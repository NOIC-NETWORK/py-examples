# py-examples

Python 算法与编程练习题集，主要面向 OJ（Online Judge）竞赛与算法学习场景。

## 简介

本仓库收录了一系列使用 Python 实现的经典算法、数据结构与基础编程题目，涵盖：

- **基础语法练习**：三数求最大、倒序输出、闰年问题、完数、回文数、水仙花数、四叶玫瑰数、猴子吃桃、百鸡百钱 等
- **排序与搜索**：冒泡排序、二分法（递归版）、二分法升级版
- **递归与分治**：递归阶乘求和、斐波那契数列、字符串排列组合
- **算法思想**：模拟退火、大衍数列、快乐数、猜年龄
- **字符串处理**：python 实现 split 方法、单词分析
- **其他小工具**：括号有效性检测器、打印菱形、剪刀石头布、迭代模拟器、二分法模拟器

题目难度从入门到中等不等，适合刷题练手、理解常见算法范式。

## 使用说明

### 环境要求

- Python 3.x（代码中部分老脚本使用了 `printf` 占位符风格，建议直接阅读源码对照运行）
- 个别进阶题目（如 `退火算法.py`）依赖 `numpy` 与 `matplotlib`：
  ```bash
  pip install numpy matplotlib
  ```

### 运行方式

Windows 下建议直接双击 `.py` 文件或在命令行执行：

```bash
python 冒泡排序.py
python 退火算法.py
```

> 注：多数脚本末尾带有 `os.system("pause")`，在命令行运行结束后会暂停等待按键。
